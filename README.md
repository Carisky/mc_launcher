# Custom Minecraft Launcher (Electron + React)

## Конфигурация
- `GAME_ROOT` — отдельная папка игрового профиля (не трогаем ваш .minecraft).
- `FORGE_VERSION` — полная строка версии Forge для 1.12.2, например `1.12.2-forge-14.23.5.2860`.
- `GITHUB.OWNER/REPO/BRANCH` — откуда тянуть модпак. ZIP скачивается с codeload.github.com.
- `GITHUB.SUBDIR` — если моды лежат не в корне, укажите относительный путь (например `client/mods`).
- `DELETE_EXTRA_MODS: true` — удалить лишние .jar в папке `mods`, которых нет в репо.

## Где лежат файлы
- Моды — `runtime/mods`.
- Остальное — `runtime/` (assets, libraries, versions) тянет `minecraft-launcher-core` при первом запуске.

## Типовые проблемы
- **Java**: библиотека использует встроенный загрузчик; если локальная Java не найдена, скачает нужную. Можно указать `javaPath` в `main.js`.
- **Антивирус**: может задерживать первый запуск из-за большого числа скачиваний.
- **Forge версия**: убедитесь, что строка совпадает с существующей, иначе загрузчик не найдёт json.
