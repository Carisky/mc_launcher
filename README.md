# Custom Minecraft Launcher (Electron + React)

Electron‑лаунчер с оффлайн-авторизацией, синхронизацией модов из GitHub и поддержкой нескольких модпаков/профилей игроков. UI работает на React без сборщика (Babel в рантайме).

## Конфигурация (`config.json`)

| Ключ | Описание |
| --- | --- |
| `GAME_ROOT` | Базовая папка, куда кешируются профили, моды, Forge и пользовательские настройки. |
| `FORGE_VERSION` | Версия Forge по умолчанию. Используется, если у модпака не задан собственный `forgeVersion`. |
| `DEFAULT_RAM_MB` | Значение оперативной памяти, которое подставляется в форму при первом запуске и служит дефолтом для новых профилей. |
| `MIN_RAM_MB` | Минимальный объём памяти (аналог `-Xms`). Лаунчер автоматически ограничивает ввод, чтобы `Xms ≤ Xmx`. |
| `JAVA_ARGS` | Дополнительные параметры JVM. Флаги `-Xmx/-Xms` автоматически фильтруются, т.к. управляются через UI. |
| `MODPACKS[]` | Описание модпаков. Для каждого: `id`, `name`, `description`, `icon`, `forgeVersion`, `github.{OWNER,REPO,BRANCH,SUBDIR}`, опционально `gameRoot` (свой путь внутри `GAME_ROOT`). Если массив отсутствует, используется единый модпак на основе верхнеуровневых полей. |
| `DELETE_EXTRA_MODS` | При `true` лаунчер удалит `.jar`, которых нет в синхронизированном архиве. |

### Пример блока модпака

```json
{
  "id": "dtm",
  "name": "DTM Modpack",
  "description": "Forge 1.12.2. Синхронизируется из GitHub.",
  "icon": "https://raw.githubusercontent.com/github/explore/main/topics/minecraft/minecraft.png",
  "forgeVersion": "1.12.2-forge-14.23.5.2860",
  "github": {
    "OWNER": "your-github",
    "REPO": "your-modpack-repo",
    "BRANCH": "main",
    "SUBDIR": "mods"
  }
}
```

Все пользовательские настройки (выбранный модпак, ник, RAM, профили) сохраняются в `runtime/user-settings.json`.

## Возможности UI

- **Плитки модпаков** — выбор любой сборки из `config.json`. Для каждого отображаются иконка, описание и версия Forge.
- **Профили игроков** — быстрые пресеты никнейма и объёма RAM. Создавайте, переименовывайте и удаляйте в один клик.
- **Стабильный выбор RAM** — введённое значение и активный профиль сохраняются между запусками.
- **Быстрые действия** — синхронизация модов из GitHub, открытие папки `mods`, запуск клиента.
- **Мониторинг** — прогресс скачивания, статусные сообщения и лог запуска с авто-пролистыванием.

## Где лежит что

- Игровой кеш и версии: `<GAME_ROOT>` или `profiles/<modpackId>` при нескольких модпаках.
- Моды: `<GAME_ROOT>/mods` или `profiles/<modpackId>/mods`.
- Пользовательские настройки: `<GAME_ROOT>/user-settings.json`.
- Forge инсталлеры: `<GAME_ROOT>/forge`.

## Сборка `.exe`

1. **Подготовьте иконку**  
   - Создайте каталог `build/` в корне проекта.  
   - Поместите туда файл `icon.ico` (512×512 px, 32‑bit).  
   - Преобразовать PNG → ICO можно через [icoconvert.com](https://icoconvert.com) или локально:  
     ```bash
     magick convert icon.png -define icon:auto-resize=256,128,64,48,32,16 build/icon.ico
     ```

2. **Установите зависимости**  
   ```bash
   npm install
   ```

3. **Соберите установщик для Windows**  
   ```bash
   npm run build:win
   ```

   Скрипт использует `electron-builder` и сформирует `dist/` с EXE/NSIS‑инсталлером и распакованной директорией приложения.

4. **Настройка**  
   - `package.json > build` содержит `productName`, `appId`, конфигурацию NSIS. При необходимости измените путь к иконке, название или режим установки (one-click).  
   - Дополнительные файлы, которые нужно включить в сборку, добавляются в массив `build.files`.

## Типовые вопросы

- **Java** — `minecraft-launcher-core` загрузит собственную JRE, если локальная не найдена. При необходимости задайте `javaPath` в `main.js`.
- **Антивирус** — первый запуск скачивает много файлов; добавьте `runtime/` в исключения, чтобы избежать задержек.
- **Разные версии Forge** — укажите `forgeVersion` в конкретном модпаке. Лаунчер скачает и закеширует нужный инсталлер автоматически.
- **Доп. контент** — логику синхронизации можно расширить (configs, resourcepacks): добавьте отдельные IPC/функции по аналогии с `syncModsFromZip`.

## Скрипты

```bash
npm install      # Установка зависимостей
npm start        # Запуск лаунчера
```

После старта заполните `config.json`, запустите `npm start`, выберите модпак/профиль, синхронизируйте моды и запускайте игру. Удачной охоты! 🛠️🪓
